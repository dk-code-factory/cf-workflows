# cf-workflows

PR workflows for Codex and Claude, built on
[Agent Workflow](https://github.com/dk-code-factory/agent-workflow).

This repository is the starting point for an independent successor to
[dk-workflows](https://github.com/dk-code-factory/dk-workflows). It will reuse the
portable PR-fix workflow and expand toward the full skill suite.

The project is in planning. There is no runnable implementation yet.

## Plan

The [implementation epic](https://github.com/dk-code-factory/cf-workflows/issues/10)
links the delivery stages, acceptance criteria, upstream defects, and required
Agent Workflow changes.

The planned suite includes configuration-agent validation of custom prompts and
skills, native host skill execution, durable recovery, and publication governed
by explicit permissions.
